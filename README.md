# مجتمع نون متحد

موقع تعريفي بمجموعات الواتساب لتطوير مهارات الكادر النسائي في قطاع خدمة حجاج الداخل.

## النشر
الموقع منشور عبر GitHub Pages من فرع `main` مباشرة.

## تحديث روابط الواتساب
عدّلي كائن `WHATSAPP_LINKS` في بداية ملف `app.js` فقط.

## الملفات
- `index.html` الصفحة الرئيسية
- `style.css` الهوية والألوان
- `app.js` الروابط والتفاعلات
- `logo.png` شعار المجتمع
